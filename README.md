#  Mini Portal de Colombia - API Consumer

## 📝 Descripción
Este es un proyecto web educativo desarrollado para practicar el consumo de APIs externas mediante JavaScript. 
El portal permite explorar información oficial de Colombia obtenida en tiempo real desde la API pública `api-colombia.com`. 

El sitio incluye tres secciones principales:
1.  **Inicio:** Información general del país (Capital, población, moneda).
2.  **Presidentes:** Listado histórico ordenado por año de mandato.
3.  **Sabores de Colombia:** Catálogo de platos típicos con su descripción y departamento de origen.

## 🚀 Tecnologías Usadas
- **HTML5:** Estructura semántica de las páginas.
- **CSS3:** Diseño responsivo con **Grid Layout** y **Flexbox**.
- **JavaScript (ES6+):** 
    - Consumo de datos con **Fetch API**.
    - Manejo de asincronismo con **Async/Await**.
    - Manipulación dinámica del **DOM**.
    - Manejo de errores con **Try/Catch**.

## ⚙️ Requisitos del Proyecto (Cumplidos)
- [x] Mínimo 2 páginas HTML conectadas.
- [x] Uso de `fetch` para obtener datos.
- [x] Mostrar mínimo 15 elementos por página.
- [x] Mensaje de carga mientras se obtienen los datos.
- [x] Manejo de errores con `.catch` o `try/catch`.
- [x] Reemplazo de imágenes rotas mediante lógica de JS.
- [x] **Extras:** Ordenamiento de presidentes por año y contador de platos típicos.
